prashna

Live Q&A and quizzes for any session with an audience

Who takes part

Any event with an audience

training, lectures, workshops, town halls and meetups

Admin

creates sessions and authors quizzes; password or GitHub sign-in

Moderator

runs the room; a private link delegates it to a co-host

Participants

join by code or QR on their phones, anonymous by default

Projector

join code, QR, top questions and the current quiz on the big screen

What happens live

1

Open a session

not started, live, then ended; one join code

2

Ask and upvote

anonymous questions; the moderator responds or removes

3

Run a quiz

reveal results question by question, with optional live counts

4

Rate the session

one to five stars plus comments, when the moderator opens rating
